OWASP Top 10 for LLM Applications 2025: apps that call a model. Say which add work here:
- LLM01 Prompt Injection: user or fetched text reaches a prompt.
- LLM02 Sensitive Information Disclosure: secrets or personal data in prompts, context or output.
- LLM03 Supply Chain: new model, dataset, plugin or package.
- LLM04 Data and Model Poisoning: training, fine-tuning or retrieval data from untrusted sources.
- LLM05 Improper Output Handling: model output rendered, executed or passed to another system.
- LLM06 Excessive Agency: tools, permissions or actions given to the model.
- LLM07 System Prompt Leakage: secrets or rules held in the system prompt.
- LLM08 Vector and Embedding Weaknesses: vector stores, retrieval access control.
- LLM09 Misinformation: answers users rely on without a check.
- LLM10 Unbounded Consumption: no limit on tokens, calls, cost or request rate.
