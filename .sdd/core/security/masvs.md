OWASP MASVS v2: mobile app security. Say which groups add work here:
- MASVS-STORAGE: data written to device storage, logs, backups, clipboard.
- MASVS-CRYPTO: encryption, hashing, keys, randomness.
- MASVS-AUTH: login, biometrics, local auth, session handling.
- MASVS-NETWORK: connections, TLS, certificate pinning.
- MASVS-PLATFORM: permissions, IPC, WebViews, deep links, UI exposure.
- MASVS-CODE: updates, dependencies, input handling, build settings.
- MASVS-RESILIENCE: tamper, root and debugger detection, obfuscation.
- MASVS-PRIVACY: data collected, consent, user control.
