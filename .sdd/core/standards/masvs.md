OWASP MASVS v2: mobile app security.
MASVS-1 MUST protect data written to device storage, logs, backups and the clipboard (STORAGE).
MASVS-2 MUST use vetted cryptography for encryption, hashing, keys and randomness (CRYPTO).
MASVS-3 MUST authenticate login, biometrics, local auth and sessions securely (AUTH).
MASVS-4 MUST secure connections with TLS and certificate pinning (NETWORK).
MASVS-5 MUST limit permissions, IPC, WebViews, deep links and UI exposure (PLATFORM).
MASVS-6 MUST keep updates, dependencies, input handling and build settings safe (CODE).
MASVS-7 SHOULD resist tampering, rooting and debuggers, and obfuscate where it matters (RESILIENCE).
MASVS-8 MUST limit data collected, ask consent and give users control (PRIVACY).
